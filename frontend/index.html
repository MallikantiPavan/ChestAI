About ChestAI

ChestAI is a research-grade platform for AI-assisted chest radiograph interpretation. It uses a DenseNet + ECA architecture trained on multi-label pathology classification, with Gradient-weighted Class Activation Mapping (GradCAM) for visual explainability.

ModelDenseNet-ECA
ClassesAtelectasis, Cardiomegaly, Consolidation, Edema, Pleural Effusion
ExplainabilityGradCAM (last DenseNet block)
InputGrayscale chest X-ray, 224×224px
Threshold0.5 (adjustable per session)
BackendFastAPI + PyTorch

Research use only. This tool is not a substitute for clinical diagnosis or the judgment of a qualified radiologist. Always seek professional medical advice.
